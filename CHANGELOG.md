## 0.1.2

- Publish the current framework as an installable `best_arm` package, with all
  registered algorithms and the `multi-arm` console command.

  examples, and a comparison that writes JSON and a plot.
- Document installation directly from GitHub, public APIs, configuration, and
  current implementation limitations.
- Add smoke tests, package verification, CI, and versioned release publishing.
- Exclude local research drafts, results, editor files, and environments.
